IMPLEMENTATION PATH
Keep the existing node-graph data model. Add a character token widget on top of the map canvas. Position = backend km progress → bezier path interpolation. Walk animation triggers when km increases from a new activity. Pure Flutter CustomPainter + AnimationController — no new engine needed.
CHARACTER SPRITE OPTIONS
Option A — LPC Spritesheet (CC-BY-SA): 64×64px walk cycle from github.com/jrconway3/Universal-LPC-spritesheet · 9 walk frames · CSS background-position animation.

Option B — Kenney Top-Down (CC0): simple isometric token from kenney.nl/assets/top-down-shooter.
KEY MECHANICS
Movement is earned, not tapped — hero walks when workouts are logged. Idle float animation on map when no journey active. Footprint trail fades in behind walking character. XP chips float up on movement. Zone arrival triggers full burst + bottom sheet reveal.

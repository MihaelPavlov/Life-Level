📖 STORY NPC
Spawns on a specific path segment, persists 24–48h. One-time dialogue per journey. Grants lore entry + small XP. Optional branching response that gives minor mechanical bonuses (+STR flavor, hint unlock). Never blocks progress. Disappears when the Walker leaves the segment or timer expires. Some are recurring on repeat region traversal.
🛒 WANDERING MERCHANT
Spawns anywhere on any active path edge for 5–24h (random window). Stocks 3–5 items from a rarity-weighted pool. Purchased with XP. Does NOT block progress — Walker walks past the merchant and can shop any time while on that segment. Timer shown in red below 4h to create urgency. Backend: same entity as planned in Phase 7 Random Events.
💀 PATH BLOCKER (AMBUSH)
Rare spawn (10–15% chance per edge traversal). FREEZES Walker progress — km no longer accumulate toward destination until boss is defeated. 3-day timer. Damage via normal activity logging (reuses BossService.CalculateDamageFromActivity). Has its own HP pool separate from zone bosses. Rewards: XP + uncommon item drop + path cleared. Shown as red BLOCKING badge on the trail node.

Updated Direction

This version keeps the ARPG inventory flavor but preserves the app structure. The Inventory tab is only the item grid. The Equipment tab uses an aligned paperdoll layout with a larger Clothing slot as the center piece.

1
Same grid for every itemUse one tile size for clothing, tracker, gloves, footwear, accessories, consumables, and map items.
2
No backpack section labelThe inventory itself is the backpack/storage surface, so the section label is simply Inventory.
3
Fits existing Life-Level styleUses current app colors, profile tabs, compact cards, bottom nav, and stat-chip style action buttons.
4
Equipment paperdollUse positioned slot tiles around the larger Clothing slot for Headwear, Gloves, Tracker, Footwear, Accessory, and Bag.

Home v4 · hero render — ascension spec

One base drawing per class — never rebuilt from gear. The same hero ascends with rank (Novice → Legend, the ladder that already exists). Each rank switches on more FX/prop layers; ★ sub-steps (XP within the rank) scale their intensity. Below: exploded tier cards, the ★ ramp, the 8-layer matrix, the asset manifest, motion spec, and the data model.

Data model — client-derived, no new backend
class HeroTierConfig { HeroTier tier; // novice|warrior|veteran|champion|legend int stars; // 1..3 HeroClass classId; // picks hero/<class>/base.png SeasonTheme season; // re-tints every layer } tier = HeroTier.values[profile.rankIndex]; // 1:1 with the rank ladder stars = (profile.xpIntoRank / profile.rankSpan * 3).ceil().clamp(1, 3); season = seasonProvider.theme; // ember / teal / crimson … // HeroStage(config) = Stack([ bg, ground, backProp, aura, hero, // head, hand, particles, frame ])
● Baked: per-class base render (~5) ✦ Layer: 9-layer stack · tier + ★ + season

Equipped gear stays in the Home gear-slot row; a per-item paper-doll rig is Phase 5+ / out of scope. Not in this board (offered): a mount silhouette beside the hero from Champion+, and the "where it renders" surface table (Home stage / profile card / leaderboard frame / share image).

# Life-Level Icon Prompts - Hand-Drawn Clean Sticker

Use these settings for every icon:

- Master size: `1024x1024`
- Export sizes: `512x512`, `256x256`, `128x128`, `64x64`, `32x32`
- Format: transparent PNG if supported
- Fallback background: flat `#00ff00` chroma key
- Style target: friendly hand-drawn clean sticker icon, flat color, dark ink outline, readable in a dark mobile app UI

Use this negative prompt for every icon:

```text
AI-generated look, glossy 3D, over-rendered fantasy art, cinematic lighting, excessive glow, particle effects, realistic texture, plastic shine, complex background, random decorations, too many tiny details, text, letters, watermark, photorealism
```

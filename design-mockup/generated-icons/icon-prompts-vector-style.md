# Life-Level Icon Prompts - Clean Vector Style

Use these settings for every icon:

- Master size: `1024x1024`
- Export sizes: `512x512`, `256x256`, `128x128`, `64x64`, `32x32`
- Format: transparent PNG if supported
- Fallback background: flat `#00ff00` chroma key
- Style target: clean hand-designed vector mobile game icon, not glossy AI fantasy art

Use this negative prompt for every icon:

```text
AI-generated look, over-rendered, glossy 3D, cinematic lighting, excessive glow, particles, hyper-detailed, painterly fantasy art, realistic texture, plastic shine, random decorations, complex background, text, letters, watermark, cluttered composition
```

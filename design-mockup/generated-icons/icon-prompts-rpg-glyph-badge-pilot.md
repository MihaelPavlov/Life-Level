# Life-Level Icon Prompts - RPG App Glyph Badge Pilot

Use these settings for every icon:

- Master size: `1024x1024`
- Export sizes: `512x512`, `256x256`, `128x128`, `64x64`, `32x32`
- Format: transparent PNG if supported
- Fallback background: flat `#00ff00` chroma key
- Style target: clean RPG mobile app glyph-badge, readable in a dark mobile app UI

Use this negative prompt for every icon:

```text
AI-generated look, generic stock icon, glossy 3D, over-rendered fantasy art, cinematic lighting, excessive glow, particle effects, realistic texture, plastic shine, complex background, random decorations, too many tiny details, text, letters, watermark, photorealism
```

## Style Rule

```text
70% familiar icon idea, 20% Life-Level fitness RPG detail, 10% hand-made imperfection.
Keep the icon simple enough for navigation, but more custom than a generic icon set.
Use a bold readable silhouette, dark ink outline, flat color fills, limited 3-4 color palette, and one soft inner shadow.
```

## Pilot Icons

### Home

```text
Context: Life-Level is a dark-themed mobile fitness RPG where real workouts become XP, quests, stats, rewards, and character progression.

Create a clean RPG mobile app icon for Home.
Keep the familiar home icon idea, but make it feel like the player's small RPG home base.
Show a simple chunky house or tavern silhouette with a warm door shape, a small roof banner, and one tiny star badge above the entrance.
Use a compact glyph-badge composition, bold dark outline, flat fills, slightly hand-drawn edges, muted red roof, warm tan walls, soft yellow door accent, and charcoal outline.
Readable at 32px and 64px.
Centered composition, transparent background.
No text, no letters, no watermark, no glossy 3D, no realistic lighting, no painterly detail, no excessive glow, no particles.
Size: 1024x1024
```

The new third layer

  • Hub (unchanged) — Power, Momentum, etc. Tap opens the category, revealing its 4 sub-branches.
  • Sub-branch (new, "extendable") — one per node type the category already used (Quest Path, Streak Path, Boss Path, Identity Path), sized between hub and skill, with a small badge showing how many ranks are nested inside. Tap zooms in further and reveals its skills instead of opening the detail sheet directly. A sub-branch with no unlocked ranks yet renders dashed/dim, same as a locked skill.
  • Skill ranks (the original 4 skills per category, unchanged) — "rank 1" is exactly the existing authored skill; "rank 2" is generated via makeRankTwo(): title + " II", locked unless rank 1 is completed (then it becomes available), description/reward derived from rank 1's own text.

The old computeCategoryFit(cat) became a generic computeFit(anchor, items) — the same bounding-box math now runs at whichever layer is open (hub+sub-branches, or sub-branch+skills), so the auto-fit and label counter-scale behavior described below applies unchanged at both depths.

How auto-fit + zoom-independent labels work

Before the camera moves to a new layer, the script walks that layer's anchor node + its items in world space to find minX/maxX/minY/maxY, pads the box by ~80px, then solves zoom = min(viewportW / boxW, viewportH / boxH), clamped to [0.55, 1.8] — the cap was raised slightly from the 2-layer version since a single sub-branch + its 2 skills is a much smaller cluster than a full category, and can afford to zoom in further.

Separately, every applyCamera() call sets --label-scale: 1 / camera.zoom as a CSS custom property on the world container, and each .node-label reads it back via scale(var(--label-scale)) — the two factors cancel out, so labels render at a fixed screen size at any depth.

How it maps to Life-Level's Adaptive Skill Tree

Center = Class root (Ranger). The 8 hubs are the 4 Behavior branches (Power, Momentum, Focus, Hybrid) and 4 Motivation branches (Explorer, Hunter, Discipline, Tactician). Sub-branches group by node type — Quest, Travel, Boss, Streak, Identity — and each contains the plan's example perk as rank 1, with a generated rank 2 above it. The dashed ring around the center cloud is the hidden mastery branch, unlocked after exploring 3 categories.

This variant adds a real third layer (hub → sub-branch → skill ranks) instead of jumping straight from hub to skill, using the same auto-fit camera and zoom-independent labels validated at the 2-layer depth — both now run generically at whichever layer is open. Sub-branch content (rank 2 of each skill) is templated rather than hand-authored per node; a production build would want bespoke copy for each, per the source doc's node-design guidance.

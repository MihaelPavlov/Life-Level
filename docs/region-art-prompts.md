# Region artwork prompts

Use these descriptions as the canonical scene prompt for each region. Generate two text-free assets per region:

- **Banner:** wide cinematic composition, 15:7 aspect ratio, primary landmark kept away from the lower text-safe area.
- **Trail background:** portrait composition, 1:2 aspect ratio, readable route through the scene, quiet center lane for map nodes.

Shared style suffix:

> Dark fantasy mobile RPG environment illustration, painterly stylized realism, atmospheric depth, cohesive teal-black Life-Level palette with region-specific accent colors, strong silhouettes, no characters, no UI, no text, no logo, no watermark. Preserve clean negative space for overlaid white interface text.

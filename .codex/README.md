# Codex Project Context

This folder contains Codex-specific project context derived from the existing `.claude` setup.

## Files

- `AGENTS.md`: primary project guide for Codex.
- `agents/`: role briefs converted from `.claude/agents`.
- `skills/`: local Codex skills for backend, Flutter UI, and game logic work.
- `prompts/`: command-style prompts converted from `.claude/commands`.

## Use

Start with `AGENTS.md`.

Use the local skills when working in their area:

- `skills/lifelevel-backend/SKILL.md`
- `skills/lifelevel-flutter-ui/SKILL.md`
- `skills/lifelevel-game-engine/SKILL.md`

The original Claude files remain in `.claude/` as source references.
